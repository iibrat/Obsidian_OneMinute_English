- 【学习节奏结论，影响设计】讨论"批量淘完再写"vs"逐个写完再淘"哪个更像认真学习。结论采用**小批量交替**：**每次只淘 3 篇 → 必须写完这批的种子才准淘下一批**。四条理由：① 产出占比决定学习性质，批量淘会把时间花在输入上，正是用户 README 里自述的老毛病（"一直在方法技巧上，很少真正练习"）；② 判断力需要即时反馈——只有马上把种子写成 60 秒才知道这句圈得好不好，隔几天再写校准就糊了；③ 间隔效应要的是分钟到小时级而非天级，淘 3 篇的间隔刚好迫使回想上下文（desirable difficulty）又不至于忘干净；④ 囤积未写种子会产生心理负担导致逃避。
  - **对插件的硬约束**：淘金队列默认只放 3 篇，写完自动补下一批，**未写完不允许继续淘**（可用不可绕过的 UI 限制而非设置项）。
  - **例外**：粗筛（快速丢弃素材）可以批量；素材本身极短（一条微博）无所谓；围绕某主题做资料搜集时批量淘合理。因此淘金要拆成「粗筛（可批量）」与「精淘并标记能写（必须与写配对）」两个子阶段。
