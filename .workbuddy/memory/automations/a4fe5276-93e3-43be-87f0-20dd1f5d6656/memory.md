## 经验与坑

- **总结目录已迁到库根 `每日总结/`**（用户要求，避免 find 把任务自身产物扫进变更）；排除关键词也相应改成 `每日总结`。
- 另一台电脑的副本任务（id `80f2d669-02be-45fd-86c0-72ddeca988ed`）路径仍是旧的 `收集箱/每日总结/`，**未同步**，需要用户在那台机器上手动改。
- `素材状态` 属性目前在 `一分钟口语表达/` 下**只有日期命名的文件有**（如 `2026年10月04日.md`），其余旧素材用的是 `来源/生成时间/kanban_order` 或 `状态`，判断待淘时以 `素材状态: []` 为准。
- `obsidian create` 的 `content` 里 `\n` 能正确换行；但**内容较长的总结用 Write 直接写文件更稳**（frontmatter 也不会被改写），Obsidian 会自动索引外部变更。
- find 扫变更时记得排除 `.obsidian/.trash/.agents/.workbuddy/附件/收集箱/每日总结`。
- 坚果云同步会把修改时间刷成开机当天，补账时要结合文件名日期归位。
